# 微波技术自学教材

11 章、作业附录、独立习题解析与公式索引，面向 EST3303 课程的原创学习材料。

网站采用通信原理教材的阅读布局，支持全文搜索、深浅主题、字号调整、章节翻页及浏览器本地阅读记录。无需登录。阅读记录不跨设备同步，不代表真实学习成绩。

公式通过 KaTeX 预先生成；字体与样式随站点托管，无第三方 CDN 依赖。本站不分发课程课件、录播或原试卷文件。课程范围与使用限制以站内说明为准。

维护时，在本地同级 `../教材/` 更新 Markdown，安装 `package.json` 依赖后运行 `node build.cjs`。发布前检查站内链接、锚点与公式；GitHub Pages 从 main 分支根目录发布。
